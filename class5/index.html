Reto 01 · 5 minutos

Estructura básica de HTML

HTML

Meta: completar una página con html, head, body, header, nav, section, article, ul, ol y li.

Microlección: ¿para qué sirve cada etiqueta?

<html> contiene toda la página. <head> guarda información que no siempre se ve, como el título y los enlaces a CSS. <body> contiene lo visible para el usuario.

<header> presenta la página, <nav> agrupa enlaces de navegación, <section> divide temas y <article> representa un contenido independiente.

Las listas se construyen con <ul> para viñetas, <ol> para numeración y <li> para cada elemento.

Ejemplo 
<header>
  <h1>Mi sitio</h1>
</header>

<section id="aprendizaje">
  <article class="tarjeta">
    <h2>Tema</h2>
    <ol>
      <li>HTML</li>
      <li>CSS</li>
    </ol>
  </article>
</section>

Reto 02 · 6 minutos

Etiquetas de contenido, imágenes y enlaces

HTML

Meta: usar títulos h1 a h6, párrafos, listas, imagen, enlace externo, enlace interno, id y class.

Microlección: contenido y atributos

Los títulos <h1> a <h6> organizan la jerarquía: <h1> es el título principal y los demás son subtítulos. El párrafo <p> sirve para escribir texto explicativo.

La etiqueta <img> muestra imágenes. Usa src para la ruta, alt para describir la imagen, width para el ancho y class para aplicar estilos.

Los enlaces <a href="..."> pueden ser externos, como una página web, o internos, como #galeria. id identifica un único elemento y class permite reutilizar estilos en varios elementos.

Ejemplo 
<h1 id="arriba">Galería digital</h1>
<p>Esta sección muestra imágenes.</p>

<a href="#galeria">Ir a galería</a>
<a href="https://developer.mozilla.org/">MDN</a>

<img src="https://picsum.photos/300/180"
     alt="Imagen de práctica"
     width="300"
     class="foto">

Reto 03 · 7 minutos

Relación HTML + CSS y selectores

CSS

Meta: reconocer <link rel="stylesheet" href="styles.css">, usar selectores de etiqueta y clase, y aplicar propiedades CSS básicas.

Microlección: conectar CSS y crear reglas

HTML define la estructura y CSS define la apariencia. Para conectar una hoja externa se usa <link rel="stylesheet" href="styles.css"> dentro de <head>.

Un selector de etiqueta aplica estilos a todos los elementos de ese tipo, por ejemplo p o body. Un selector de clase empieza con punto, por ejemplo .tarjeta, y afecta a los elementos que tengan esa clase.

Propiedades como background-color, color, font-size, margin, padding, border, width, height, text-align, text-decoration y list-style modifican el diseño.

Ejemplo 
<link rel="stylesheet" href="styles.css">

body {
  background-color: #f1f5f9;
  color: #111827;
  font-size: 18px;
}

.tarjeta {
  margin: 20px;
  padding: 16px;
  border: 2px solid #2563eb;
  width: 300px;
  height: 180px;
}

Reto 04 · 7 minutos

Display: block, inline y flex

CSS

Meta: aplicar display: block, display: inline, display: flex y justify-content.

Microlección: cómo se acomodan los elementos

display: block hace que un elemento ocupe una línea completa. Es común en section, article, div y títulos.

display: inline permite que los elementos estén en la misma línea. Es común en enlaces o fragmentos cortos de texto.

display: flex convierte un contenedor en una fila o columna flexible. Con justify-content se controla cómo se distribuyen los elementos: al centro, separados o hacia los extremos.

Ejemplo 
.menu {
  display: flex;
  justify-content: center;
  gap: 12px;
}

.menu a {
  display: inline;
}

.card {
  display: block;
  margin: 10px;
  padding: 12px;
  border: 1px solid #30363d;
}
